# AI-Motion-Studio
rabic AI Motion Graphics Studio
## AI MOTION STUDIO

استوديو عربي لإنشاء موشن جرافيك احترافي
باستخدام الذكاء الاصطناعي.

### أهداف المشروع
- إنشاء فيديوهات موشن جرافيك عربية.
- إنتاج إعلانات ثلاثية الأبعاد.
- تصميم فيديوهات تعليمية وتوضيحية.
- دعم اللغة العربية واتجاه RTL.

### التقنيات
- Remotion
- React
- TypeScript
- Three.js

### مراحل التطوير
1. تأسيس المشروع.
2. بناء نظام المشاهد والحركة.
3. إضافة القوالب العربية.
4. إنتاج أول فيديو تجريبي.
