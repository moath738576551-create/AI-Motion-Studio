# AI Motion Studio

استوديو ويب عربي لإنشاء فيديوهات موشن جرافيك عبر Remotion، مع واجهة RTL وإعدادات مناسبة للهاتف.

## ما يعمل حالياً
- تحرير المشاهد العربية: إضافة، حذف، إعادة ترتيب، وتعديل العنوان والوصف والمدة.
- قوالب بداية للإعلانات الفاخرة وكشف الهوية والقصص والشرح.
- إعدادات 9:16 و16:9 و1:1، ومعدلات 24/30/60 FPS ودقات 720/1080/2160.
- حفظ المشروع في متصفح الجهاز وتصدير/استيراد JSON.
- رندر MP4 مخصص من بيانات المشروع عبر GitHub Actions، ثم تنزيله من Artifacts.
- نشر واجهة الاستوديو على GitHub Pages عند تفعيل Pages في المستودع.

## رندر فيديو مخصص من الهاتف
1. افتح واجهة الاستوديو وحرّر المشاهد والإعدادات.
2. اضغط "تصدير إعدادات المشروع" واحفظ ملف JSON.
3. افتح Actions ثم سير العمل "AI Motion Studio Build".
4. اضغط Run workflow، والصق محتوى ملف JSON في حقل project_json. ترك الحقل فارغاً ينتج الفيديو التجريبي.
5. بعد انتهاء البناء بنجاح، افتح التشغيل ونزّل Artifact باسم AI-MOTION-STUDIO-VIDEO؛ يحتوي MP4 وملف إعدادات المشروع.

رابط التشغيل اليدوي:
https://github.com/moath738576551-create/AI-Motion-Studio/actions/workflows/build.yml

## حدود النسخة الحالية
محرك Remotion ينشئ فيديوهات من النصوص والعناصر والحركات الموجودة في المشروع. توليد صور أو فيديوهات AI، وتحريك صور يرفعها المستخدم، والشخصيات ثلاثية الأبعاد، والصوت/التعليق الصوتي، ومحرر طبقات كامل لم تُربط بعد بخدمات توليد خارجية. لا توجد مفاتيح API داخل الواجهة. قد تستغرق عمليات الرندر عالية الدقة وقتاً أطول وتستهلك موارد GitHub Actions.
